> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a Go TUI `aitop` that paints house agent occupancy at 100ms with proven names, projects, subagent counts, CPU, RSS, tokens, and cost-when-known.

**Architecture:** Dual-index. `/proc` spine on a 100ms goroutine; overlay cache off-tick; pure `Join`. Spec: `docs/superpowers/specs/2026-08-21-aitop-design.md`.

**Tech Stack:** Go 1.26, bubbletea v1.3.10, lipgloss v1.1.0, stdlib testing, no cgo.

**Work from:** `/home/aegis/Projects/aitop`

TDD on every task. Deep-tests planted failures PF-1..PF-7 are first-light, not optional. Unknown cost is `*float64` nil, never `0`. Canary `aitop-canary`.
